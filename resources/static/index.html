TB

IoT Based Toll Booth Manager

Real time control room · Core Java · no database

First start creates admin / Admin@123 and operator / Operator@123. Change them after the first login.

Passwords are stored as salted PBKDF2 hashes. Sessions use random tokens with idle and absolute expiry.

What this system does

  • RFID An ESP-style reader identifies the vehicle, the tag is validated and looked up in the booth HashMap.
  • PAY Cash, UPI or FASTag payment through the PaymentProcessor interface, with a printed receipt.
  • LIVE Every payment, login and alert is pushed to all open browsers instantly with Server Sent Events.
  • SAFE PBKDF2 passwords, brute force lockout, audit log file and role based access (ADMIN / OPERATOR).
